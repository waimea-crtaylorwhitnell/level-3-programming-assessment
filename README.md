## Project Description

This project is a very large map based game which I have based on the game Bloodborne. In this game you are trapped in a plane only known as The Hunt, your only method of escaping is to search for four one thirds of an umbilical cords (Yes I'm aware that the math doesn't math there) and consume them. This is due to them having the ability to grant one 'eyes', a term used to refer to insight in this world. With a high enough level of insight you will become able to see the true reason you are trapped within this hellish nightmare, and slay them, just like the rest.
